## 教材內容

### AGENTS.md：專案的長期記憶

每次開新對話，AI 都會忘記上次你交代的事。AGENTS.md 是放在資料夾裡的說明檔，OpenCode 每次工作前都會自動讀取，等於專案專屬的 System Prompt。
最快的建立方式：在 OpenCode 輸入 /init，它會先閱讀資料夾內容，再引導你建立或更新 AGENTS.md。
OpenCode 2 只認得 AGENTS.md 這個檔名；對話進行中修改它，下一次送出提問前就會自動套用。

### 寫什麼？越精簡越有效

判斷標準：「沒寫的話，AI 很可能會做錯嗎？」會，才寫進去；AI 本來就會的常識不用寫。
建議內容：這個專案在做什麼、資料夾怎麼分、輸出的語言與風格、完成後要怎麼檢查、絕對不能動的檔案。
全域檔（~/.config/opencode/AGENTS.md）放所有專案都適用的個人偏好；專案根目錄放整個專案的規則；子資料夾再放更細的規則。多個檔案會合併使用，請避免互相矛盾。
如果專案用 Git 管理，記得把 AGENTS.md 一起提交，團隊成員就會拿到同一套規則。

### 自訂指令：把常用提問變成 /按鈕

在專案建立 .opencode/commands/ 資料夾，放一個 Markdown 檔，例如 summary.md，檔案內容就是提問範本，之後輸入 /summary 就能使用。
範本中的 $ARGUMENTS 會換成你在指令後面輸入的文字，例如 /summary 會議紀錄.md。
檔案開頭可以加 description（說明）與 agent（指定由哪個 Agent 執行，例如 plan）。想讓所有專案都能用，就放在 ~/.config/opencode/commands/。

## 教材提示詞

### AGENTS.md 範本（文件整理專案）

```text
# 專案說明
這個資料夾用來整理課程講義與簡報素材。

# 資料夾結構
- raw/：原始資料，只能讀取，不可修改或刪除
- notes/：整理後的講義（Markdown）
- slides/：簡報大綱

# 寫作規則
- 一律使用繁體中文（台灣用語），語氣親切、句子簡短
- 專有名詞第一次出現時附一句白話解釋
- 不捏造數據；需要數據時標示「待查證」

# 完成前檢查
- 確認沒有修改 raw/ 裡的檔案
- 列出這次新增或修改了哪些檔案
```

### 自訂指令範本：.opencode/commands/summary.md

```text
---
description: 把指定檔案整理成三段式摘要
agent: plan
---

請閱讀 $ARGUMENTS，整理成以下格式，不要修改任何檔案：
1. 一句話重點
2. 三個關鍵細節（條列）
3. 我接下來可以採取的行動
```
