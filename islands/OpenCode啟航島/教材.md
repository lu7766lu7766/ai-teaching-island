## 教材內容

### OpenCode 是什麼？

OpenCode 是開源（MIT 授權）的 AI Agent。和聊天機器人不同，它能在你指定的資料夾裡讀檔、建立與修改檔案、執行指令，幫你「動手做完」一件事。
它有桌面版 App、終端機版與網頁介面，軟體本身免費，而且內建一組不需要註冊帳號就能用的免費模型。
目前最新為 OpenCode 2（V2），本島內容依 2026 年 11 月官方文件整理。

### 安裝：最簡單的是桌面版

新手推薦桌面版：到 opencode.ai/download 下載 OpenCode Desktop（macOS、Windows、Linux 皆有），像一般軟體一樣安裝。Windows 若開啟後一片空白，請安裝或更新 Microsoft Edge WebView2 Runtime。
習慣終端機的人可改裝終端機版：
macOS／Linux：curl -fsSL https://opencode.ai/v2/install | bash
已安裝 Node.js：npm install -g @opencode/cli
安裝後在終端機輸入 opencode 即可啟動。

### 選擇免費模型與注意事項

不用登入就能在模型選單（終端機版輸入 /models）選到 OpenCode 的免費模型，例如 Big Pickle，以及名稱帶「Free」的模型，如 DeepSeek V4.1 Flash Free、GLM-5.3-Flash Free、MiMo-V2.6-Flash Free、Nemotron 3.5 Lightning Free（2026/11/03 官方清單）。
免費模型都是「限時」提供，名單常更換，以模型選單為準；大家共用流量，尖峰時可能暫時無法使用，換一個模型即可。
隱私：官方說明 GLM-5.3-Flash Free 與 DeepSeek V4.1 Flash Free 的供應商不保留資料、不拿來訓練；Big Pickle、MiMo 等模型在免費期間可能使用資料改進模型；Nemotron 系列為 NVIDIA 試用端點，請勿輸入個資或機密。
想用 Gemini：到 Google AI Studio 免費建立 API 金鑰，在 OpenCode 輸入 /connect 選擇 Google 並貼上金鑰（金鑰不要分享或上傳到網路）。

### 第一個任務：Plan 先想，Build 再做

1. 先建立一個空的練習資料夾（例如桌面上的 ai-practice），用 OpenCode 開啟它。不要一開始就開重要資料夾。
2. 切到 Plan（計畫）Agent：它只規劃、不修改檔案。描述需求，例如「做一個自我介紹網頁」，先看它的計畫。
3. 計畫沒問題，再切回 Build（建置）Agent 請它動手。終端機版按 Shift+Tab 切換 Agent，或輸入 /agents 選擇。
4. 結果不滿意，輸入 /undo 復原上一輪的修改，調整說法後再試。

## 教材提示詞

### 第一個任務：自我介紹網頁

```text
請在這個資料夾建立一個單一檔案的自我介紹網頁 index.html。

需求：
- 內容：我的名字【填入】、三個興趣【填入】、一句座右銘【填入】
- 風格：簡潔、溫暖的配色，手機也能好好閱讀
- 不使用任何外部套件或網路資源

完成後告訴我怎麼用瀏覽器打開它。
```

### 請 AI 先規劃（在 Plan Agent 使用）

```text
我想要【描述你的目標】。
請先不要修改任何檔案，給我一份 3～5 步的執行計畫，並列出你需要我確認的問題。
```
