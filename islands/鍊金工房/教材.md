## 教材內容

### 從練習頁到正式工具

在星門渡口，你已經用範例一的練習頁成功呼叫 Gemini。這一站要把它「鍊」成真正能用的工具：讓 AI 記得前面聊過的內容、回傳程式能直接使用的 JSON，最後把金鑰收進後端，才能安全地給別人使用。
本站的範例三、四都沿用星門渡口範例一的 askGemini 函式，只要把送出的內容換掉就好；範例五則是一個獨立的後端程式。
金鑰規則不變：不放前端、不上網，要給別人用就一定放在後端。
年齡規則也不變：依 Gemini API 官方條款，使用者要年滿 18 歲，未滿 18 歲的學員請由師長示範。正式上線時還要注意：條款不允許把 Gemini API 用在以未成年人為對象、或可能被未成年人使用的網站或 App，例如給中小學生用的作業小幫手。

### 範例三：多輪對話與錯誤處理

API 預設每次呼叫都是全新的對話。Interactions API 會回傳一個 id，下一次呼叫時把它放進 previous_interaction_id，AI 就會接著上一輪的內容回答，不必自己重送整段歷史。
常見錯誤：400 加上 API_KEY_INVALID 表示金鑰貼錯或已被刪除；429 表示超過免費額度，請稍等或隔天再試；網路錯誤則先檢查網址與連線。把錯誤訊息顯示在畫面上，除錯會容易很多。

### 範例四：結構化輸出，讓 AI 回固定格式的 JSON

AI 平常回的是一段文字，程式很難從裡面準確取出「題目是什麼、答案是哪個」。加上 response_format，把 mime_type 設成 application/json，再用 schema（JSON Schema）描述有哪些欄位，AI 就會照這個格式回答。程式用 JSON.parse 轉成物件後，就能直接做成測驗、表格或存起來。
schema 要寫清楚欄位名稱、型別（string 文字、integer 整數、array 陣列、object 物件）和必填欄位（required）；欄位加上 description 說明用途，AI 會填得更準。
注意：有些限制（例如字數上下限）不一定會被強制遵守，程式拿到資料後仍要自己檢查一次再使用。

### 正式上線：把金鑰嵌在後端

要讓別人使用你的 AI 小工具時，正確架構是：使用者的瀏覽器 → 你自己的後端 → Gemini API。金鑰只存在後端的環境變數裡，使用者完全拿不到。
「範例五」用 Node.js（建議 22 以上，不需安裝任何套件）寫一個最小後端：金鑰放在同資料夾的 .env 檔，用 node --env-file=.env server.mjs 啟動；網頁由同一個後端提供，前端只呼叫自己的 /api/ask，程式碼裡完全沒有金鑰。
記得建立 .gitignore 並寫入 .env，確認上傳的檔案裡沒有金鑰。之後部署到任何雲端平台，也都是在平台的「環境變數／Secrets」設定填入金鑰，而不是寫進程式碼。
正式服務還要考慮：限制每位使用者的呼叫次數、檢查輸入長度，避免你的額度被別人用光。

## 教材提示詞

### 範例三：多輪對話（接著上一輪回答）

```js
// 在 <script> 最上方宣告，用來記住上一輪的 id
let lastId = null;

// 送出時帶上 previous_interaction_id，AI 就會記得前面聊過的內容
const result = await askGemini(apiKey, {
  input: document.querySelector("#question").value,
  ...(lastId ? { previous_interaction_id: lastId } : {})
});
lastId = result.id;   // 存起來給下一輪使用
out.textContent = result.text;

// 想重新開始新對話時：lastId = null;
```

### 範例四：結構化輸出，讓 AI 出三題選擇題（替換星門渡口範例一送出的內容）

```js
const result = await askGemini(apiKey, {
  input: "請依下面的主題，出 3 題四選一的選擇題：" + document.querySelector("#question").value,
  response_format: {
    type: "text",
    mime_type: "application/json",
    schema: {
      type: "object",
      properties: {
        questions: {
          type: "array",
          items: {
            type: "object",
            properties: {
              question: { type: "string", description: "題目" },
              options: { type: "array", items: { type: "string" }, minItems: 4, maxItems: 4 },
              answer: { type: "integer", description: "正確選項的位置，0 到 3" }
            },
            required: ["question", "options", "answer"]
          }
        }
      },
      required: ["questions"]
    }
  }
});

// 回傳的文字就是 JSON：轉成物件，先檢查格式再使用
const quiz = JSON.parse(result.text);
if (!Array.isArray(quiz.questions)) throw new Error("回傳格式不符：" + result.text);
out.textContent = quiz.questions.map((q, i) =>
  (i + 1) + ". " + q.question + "\n" +
  q.options.map((o, j) => "   (" + "ABCD"[j] + ") " + o).join("\n") +
  "\n   答案：" + "ABCD"[q.answer]
).join("\n\n");
```

### 範例五：正式上線，金鑰嵌在後端（server.mjs）

```js
// ① 同資料夾建立 .env，內容只有一行（不要上傳這個檔案）：
//    GEMINI_API_KEY=貼上你的金鑰
// ② 建立 .gitignore，寫入一行：.env
// ③ 把星門渡口的範例一存成同資料夾的 index.html，刪掉金鑰欄位，
//    並把 askGemini 裡的 fetch 改成呼叫自己的後端（不帶金鑰）：
//    fetch("/api/ask", { method: "POST",
//      headers: { "Content-Type": "application/json" },
//      body: JSON.stringify({ input: "你的問題" }) })
// ④ 啟動（Node.js 22 以上）：node --env-file=.env server.mjs
//    再用瀏覽器開啟 http://localhost:3000

import http from "node:http";
import { readFile } from "node:fs/promises";

const API_URL = "https://generativelanguage.googleapis.com/v1beta/interactions";

http.createServer(async (req, res) => {
  try {
    // 提供前端網頁
    if (req.method === "GET" && req.url === "/") {
      res.writeHead(200, { "Content-Type": "text/html; charset=utf-8" });
      res.end(await readFile("index.html"));
      return;
    }
    if (req.method !== "POST" || req.url !== "/api/ask") {
      res.writeHead(404).end();
      return;
    }
    let raw = "";
    for await (const chunk of req) raw += chunk;
    const { input } = JSON.parse(raw || "{}");
    if (typeof input !== "string" || !input || input.length > 2000) {
      res.writeHead(400, { "Content-Type": "text/plain; charset=utf-8" });
      res.end("問題不可空白，且不超過 2000 字");
      return;
    }
    // 由後端代為呼叫 Gemini，金鑰只在伺服器上
    const upstream = await fetch(API_URL, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-goog-api-key": process.env.GEMINI_API_KEY
      },
      body: JSON.stringify({ model: "gemini-3.5-flash-lite", input })
    });
    res.writeHead(upstream.status, { "Content-Type": "application/json; charset=utf-8" });
    res.end(await upstream.text());
  } catch (err) {
    res.writeHead(500, { "Content-Type": "text/plain; charset=utf-8" });
    res.end("伺服器發生錯誤：" + err.message);
  }
}).listen(3000, () => console.log("已啟動：http://localhost:3000"));
```
