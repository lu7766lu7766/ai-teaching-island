## 教材內容

### 什麼是 System Prompt？

每次和 AI 對話時，除了你輸入的問題，背後通常還有一段你看不到的「系統提示詞」，先告訴模型：你是誰、要遵守什麼規則、用什麼格式回答。
它就像員工的工作說明書，整段對話都有效；你的提問則像主管當天交辦的任務。
幾乎所有 AI 產品都靠 System Prompt 決定個性與能力，下一階段的 OpenCode 自訂 Agent，本質上也是「一段 System Prompt＋可用的工具」。

### 免費實作：在 Google AI Studio 設定系統指令

1. 用 Google 帳號登入 aistudio.google.com（免費，不需信用卡）。
2. 開一個新的 Chat，找到「System instructions（系統指令）」欄位，貼上本島下方的範本並修改括號內容。
3. 在下方對話框用幾個不同問題測試，看 AI 是否一直遵守你的規則。
4. 不滿意就回去改系統指令，再用同樣的問題重測，比較前後差異。
提醒：Google 可能使用免費服務中的對話內容改善產品，練習時請勿貼上個資或機密資料。

### 好的 System Prompt 長什麼樣？

建議依序寫：身分（你是誰）→ 目標（幫誰解決什麼）→ 規則（必須做／不可以做）→ 輸出格式 → 資訊不足時怎麼辦（例如先發問，不要亂猜）→ 一個示範例子。
寫具體行為，不寫空泛形容詞：「每次回答不超過 5 點」比「回答要精簡」更有效。
規則太多會互相衝突，模型也可能漏掉；先寫最重要的 3～5 條，測試後再補。
想看真實產品的寫法，可以到 OpenCode 的 GitHub 原始碼閱讀它內建的 System Prompt。

## 教材提示詞

### System Prompt 範本：簡報小幫手

```text
# 身分
你是一位擅長把複雜概念講簡單的簡報顧問。

# 目標
協助使用者把想法整理成清楚的簡報大綱。

# 規則
1. 一律使用繁體中文（台灣用語）。
2. 每頁重點不超過 3 點，每點不超過 20 字。
3. 遇到專有名詞，第一次出現時附上一句白話解釋。
4. 不捏造數據；需要數據時，標示「請自行補上來源」。

# 輸出格式
用表格呈現，欄位為「頁次｜標題｜重點｜講者備註」。

# 資訊不足時
如果不知道聽眾是誰或簡報長度，先問我，不要自己假設。
```

### 測試用提問

```text
幫我做一份介紹「生成式 AI 是什麼」的簡報大綱。
```
