## 教材內容

### API 是什麼：從聊天視窗走進自己的程式

在 Gemini 網頁上聊天，是「你」跟 AI 對話；API（應用程式介面）則是讓「你的程式」直接跟 AI 對話。學會 API，就能把 AI 放進自己做的網頁、表單、小工具裡。
一次 API 呼叫只有三個元素：① 網址（要找哪個服務）② API Key（證明你是誰，像通行證）③ 用 JSON 格式寫的請求內容（用哪個模型、要問什麼）。AI 回傳的結果同樣是 JSON，程式再從裡面取出文字。
本課使用 gemini-3.5-flash-lite：Gemini 3.5 系列中速度最快、成本最低的模型，Gemini API 免費方案即可使用，很適合練習與做小工具。
本課範例採用 Google 建議新專案使用的 Interactions API（網址結尾為 /interactions）。網路上很多舊教學使用 generateContent，也還能用，但寫法不同，看到時不要混在一起。

### 在 Google AI Studio 免費申請 API Key

① 用 Google 帳號登入 Google AI Studio（aistudio.google.com），第一次使用需同意服務條款。
② 進入「API Keys」頁面（左側選單或首頁的 Get API key）。新使用者通常已自動建立好專案與金鑰，也可以按「Create API key」再建立一把。
③ 複製金鑰，馬上存進安全的地方（見下一段），不要貼到聊天群組或文件裡。
免費方案不需要綁信用卡。使用量有每分鐘、每天的次數上限，而且是以「專案」計算，不是以金鑰計算；實際額度請看 AI Studio 裡的用量與限制頁面，額度用完會收到 429 錯誤，等一下或隔天再試即可。
注意：免費方案送出的內容可能被 Google 用來改善產品，請不要送出個資、成績、客戶資料或公司機密。不打算付費就不要開啟帳單（Billing）。

### 金鑰安全：不能放前端，也不能放上網

API Key 就像你的密碼加上信用卡：別人拿到就能用你的額度、以你的名義呼叫 AI；如果你的專案開了帳單，費用也會算在你頭上。
規則一：不要把金鑰寫進前端程式碼（HTML、JavaScript）。網頁送到瀏覽器後，任何人按 F12 或「檢視原始碼」都看得到，混淆或藏在別的檔案裡也沒用。
規則二：不要把金鑰放上網路。包含 GitHub（公開或私人倉庫都不要）、雲端硬碟共用資料夾、部落格文章、截圖與教學影片。網路上有程式專門在掃描外洩的金鑰。
規則三：自己想辦法保管好。可以存在密碼管理器，或放在專案的 .env 檔，並把 .env 加進 .gitignore，確保它不會被上傳。
規則四：要給別人用的網站，金鑰一定要嵌在後端伺服器（環境變數）裡，由前端呼叫你自己的後端，後端再代為呼叫 Gemini（下一站鍊金工房會帶你做）。
萬一外洩：立刻到 AI Studio 的 API Keys 頁面刪除那把金鑰，再建立新的一把。

### 範例一：前端 JavaScript 本機練習頁

先用一個 HTML 檔體驗 API：把下方「範例一」的程式碼存成 gemini-test.html，在自己電腦上用瀏覽器開啟即可，不用安裝任何東西。
這個練習頁刻意不把金鑰寫在程式碼裡：每次開啟時才把金鑰貼進密碼欄位，它只存在瀏覽器記憶體，關閉分頁就消失。即使如此，這個檔案只能在你自己電腦上練習，不要上傳到網站或分享給別人使用。
程式做了三件事：① 用 fetch 送出 POST 請求，金鑰放在 x-goog-api-key 標頭；② 請求內容寫明 model 與 input；③ 從回傳 JSON 的 steps 裡找出模型輸出（model_output）的文字。
看不懂的地方，可以把程式碼貼給 Gemini 或 OpenCode，請它逐行解釋（記得先把金鑰拿掉）。

### 範例二：加上 System Instruction 與參數

在魔法書之島學過的 System Prompt，在 API 裡叫 system_instruction，用來固定 AI 的角色與規則。
generation_config 可以調整產出：temperature 越低回答越穩定一致（適合整理、分類），越高越有變化（適合發想）；max_output_tokens 限制回答長度，避免一次用掉太多額度。
把「範例二」的 body 換進範例一的程式，就能做出一個「固定角色的小助教」。

## 教材提示詞

### 範例一：前端本機練習頁（存成 gemini-test.html，只在自己電腦開啟）

```html
<!doctype html>
<html lang="zh-Hant">
<meta charset="utf-8">
<title>Gemini API 練習</title>
<h1>Gemini API 練習（只在自己電腦使用）</h1>
<p>API Key（每次手動貼上，不寫進程式碼）：
  <input id="key" type="password" size="45" autocomplete="off"></p>
<textarea id="question" rows="4" cols="60">用三句話向新手解釋什麼是 API</textarea><br>
<button id="send">送出</button>
<pre id="answer" style="white-space:pre-wrap"></pre>

<script>
const API_URL = "https://generativelanguage.googleapis.com/v1beta/interactions";
const MODEL = "gemini-3.5-flash-lite";

// 送出請求，回傳 { id, text }
async function askGemini(apiKey, body) {
  const res = await fetch(API_URL, {
    method: "POST",
    headers: { "Content-Type": "application/json", "x-goog-api-key": apiKey },
    body: JSON.stringify({ model: MODEL, ...body })
  });
  const data = await res.json();
  if (!res.ok) {
    // 錯誤訊息有時直接回傳，有時包在陣列裡，兩種都處理
    const error = [].concat(data)[0]?.error;
    throw new Error(error?.message || "HTTP " + res.status);
  }
  // 只取最後一次提問之後、模型輸出的文字
  const steps = data.steps || [];
  const start = steps.findLastIndex(s => s.type === "user_input") + 1;
  const text = steps.slice(start)
    .filter(s => s.type === "model_output")
    .flatMap(s => s.content || [])
    .filter(c => c.type === "text")
    .map(c => c.text)
    .join("");
  return { id: data.id, text: text || JSON.stringify(data, null, 2) };
}

document.querySelector("#send").onclick = async () => {
  const out = document.querySelector("#answer");
  const apiKey = document.querySelector("#key").value.trim();
  if (!apiKey) { out.textContent = "請先貼上 API Key"; return; }
  out.textContent = "思考中…";
  try {
    const result = await askGemini(apiKey, {
      input: document.querySelector("#question").value
    });
    out.textContent = result.text;
  } catch (err) {
    out.textContent = "發生錯誤：" + err.message;
  }
};
</script>
</html>
```

### 範例二：加上 System Instruction 與參數（替換範例一送出的內容）

```js
const result = await askGemini(apiKey, {
  system_instruction: "你是親切的程式小助教。用繁體中文回答，先給結論，再用一個生活化的比喻說明，全文不超過 150 字。",
  input: document.querySelector("#question").value,
  generation_config: {
    temperature: 0.3,        // 越低越穩定，越高越有創意
    max_output_tokens: 400   // 限制回答長度
  }
});
```
